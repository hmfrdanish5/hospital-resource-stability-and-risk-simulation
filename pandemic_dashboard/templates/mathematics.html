Mathematical Foundations

Reference for the resource-allocation model, Banker's safety algorithm, and Monte Carlo collapse estimation used in the simulator. Notation follows standard operating-systems literature (Dijkstra, 1965).

1. Resource Allocation Model

Each admitted patient i is a process with m resource types:

Allocation   A[i,j] — units of resource j currently held by patient i

Maximum claim   Max[i,j] — maximum units patient i may ever require

Need   Need[i,j] = Max[i,j] − A[i,j]

Available   Avail[j] — free units of resource j

Invariants

  • 0 ≤ A[i,j] ≤ Max[i,j] for all i, j
  • Need[i,j] ≥ 0 for all i, j
  • Total[j] = Avail[j] + Σi A[i,j]

Hospital mapping: patients → processes; ICU beds, oxygen, ventilators, nurses, blood units → resource types.

2. Banker's Safety Algorithm

A state is SAFE if there exists an ordering in which every patient can complete without exhausting resources.

Work  ← Available
Finish[i] ← false  for all patients i

repeat
    find i such that Finish[i] = false  AND  Need[i] ≤ Work
    if found:
        Work  ← Work + Allocation[i]
        Finish[i] ← true
    else:
        return UNSAFE
until all Finish[i] = true
return SAFE

Vector comparison: Need[i] ≤ Work means Need[i,j] ≤ Work[j] for every resource j.

A safe sequence is the order in which patients complete during the algorithm.

3. Monte Carlo Collapse Estimation

For each patient count n = 1, 2, …, N, run T independent trials. Each trial:

  1. Sample n patients with stochastic severity and demand vectors.
  2. Attempt sequential admission (allocate initial resources).
  3. Run Banker's algorithm on the resulting state.

Admission failure: trial stops when a patient's initial allocation exceeds Avail.

Unsafe state: all n admitted but Banker's returns UNSAFE.

Collapse: admission failure or unsafe state.

P̂(collapse | n) = Kn / T

where Kn is the number of collapsed trials at load n. n50 = min { n tested : P̂(n) ≥ 0.50 } (discrete; no interpolation).

4. Wilson Score Confidence Interval

95% confidence interval for a binomial proportion p (Wilson, 1927):

p̂ = K / T

centre = (p̂ + z²/2T) / (1 + z²/T)

half-width = z / (1 + z²/T) · √(p̂(1−p̂)/T + z²/4T²)

CI = [centre − half-width, centre + half-width]

Implementation uses z = 1.96 (nominal 95%). Intervals are approximate and assume independent trials.

5. Patient Demand Generation

For severity tier s, each resource j has configured bounds [mins,j, maxs,j]:

Max[i,j] ~ Uniform(mins,j, maxs,j)

A[i,j] ~ Uniform(mins,j, Max[i,j])

ICU beds and ventilators: binary (0 or 1 unit per patient).

Severity tier is sampled from a categorical distribution (normalized user weights in the UI).

6. Phase 2: Time-Dependent Hospital Model

Discrete time with configurable step Δt (default 1 hour). Capacity is a vector process C(t). Banker's algorithm is unchanged and is evaluated on the in-care allocation snapshot at each t.

W(t) = C(t) − Atotal(t),   W(t) ≥ 0 component-wise

C(t) = W(t) + Atotal(t)

NurseCapacity(t) = round(BaseNurses × mshift(t) × mweekend(t))

effective LOS = base LOS × (1 + α) while the fatigue state is active

overflow acuity: a(t + Δt) = a(t) + r Δt

Staffing (model assumptions)

mshift equals the handover multiplier during configured handover hours and 1 otherwise. mweekend equals the weekend multiplier on configured weekend days and 1 otherwise. Calendar convention: t = 0 is Monday 00:00. These multipliers are sensitivity parameters, not measured staffing facts.

Capacity transitions

If Cj(t) would fall below current Atotal,j, the model overflows lowest-priority in-care patients (explicit Allocation release) until Atotal ≤ C(t). Holdings are never silently destroyed.

Treatment bundles

A patient enters WARD or ICU only if every component of the pathway requirement is available (all-or-nothing). Failure places the patient in ED_OVERFLOW. Overflow is not automatic system collapse; Banker's SAFE/UNSAFE is recorded separately.

Triage

Deterministic rank: Critical < Severe < Moderate < Mild (lower rank admitted first), then earlier arrival, then patient id.

Preemption

Acuity-based preemption of in-care patients is not implemented. Removing Allocation without a defined remaining Max/Need would make Banker's semantics ambiguous. That remains future work.

7. Phase 3: Empirical Calibration

External series are ingested through a cache/fallback layer. The Banker's core is unchanged. Every quantity is labeled:

  • REAL OBSERVATION — published or downloaded measurements
  • MODEL ASSUMPTION — chosen mapping not identified from microdata
  • DERIVED PARAMETER — transform of observations (rates, fitted families)
  • SIMULATED VALUE — Monte Carlo draws or offline fixtures

Arrivals

Daily counts are compared with Poisson and negative binomial using mean, variance, dispersion D = s2/x̄ (diagnostic, not a proof), log-likelihood, and AIC. Poisson is not assumed. Negative binomial uses the NB2 / Gamma–Poisson parameterization (mean μ, size θ; Var = μ + μ²/θ). The hospital-scale mean λ0 remains a model assumption (configured arrivals per step). Empirical weekday relatives give λ(t) = λ0 rdow(t) in dynamic Model C only. National daily_mean/24 is not this hospital's arrival process.

LOS

Patient-level LoS records are not ingested. Rees et al. (2020) outside-China Q25/Q50/Q75 are used for quantile-based distribution reconstruction, not maximum-likelihood fitting. Candidates (Gamma, Weibull, Lognormal) are scored by quantile reconstruction SSE = Σ (Qmodel − Qobs)2 on those three points. This is not a formal goodness-of-fit test. Gamma predicted quantiles use the Wilson–Hilferty approximation, so that family's SSE is not on identical exact-quantile footing. The selected family is sampled in the dynamic Model C run (days × 24 hours), not in the static Banker's collapse sweep.

Model A / B / C (executable scope)

  • Experiment family A — Static Banker collapse: A = independent demand; B = joint ICU/vent given severity; C = same demand as B. Arrival and LOS do not affect n50. Do not call this a fully calibrated collapse model.
  • Experiment family B — Dynamic empirically informed simulation: A and B use configured arrivals and uniform LOS; C uses calibrated arrival family, weekday λ(t), and quantile-reconstructed LOS. Not individual-hospital census.

External signal

f(X) = clip(X / 50000, 0.5, 3.0) scales the Monte Carlo patient ceiling only. X is latest-available public smoothed cases. The reference 50000 and clip bounds are model assumptions, not hospital truth, and were not empirically learned. See docs/MATHEMATICAL_MODEL.md.

n50

n50 = min { n tested : p̂(n) ≥ 0.50 }. Discrete; no interpolation. Elasticity εk inherits Monte Carlo variability in n50.

Dependence

National hospital vs mechanical-ventilation occupancy may be correlated. That is not a within-patient copula. Model B (static) samples ICU and ventilator jointly given severity. A copula is not used.

Uncertainty

Wilson intervals: simulation uncertainty under a fixed model. Arrival-mean interval is an IID percentile bootstrap and does not preserve time-series dependence. ±5/10/20% sweeps: parameter sensitivity. Neither is a real-world forecast interval for a named hospital.
