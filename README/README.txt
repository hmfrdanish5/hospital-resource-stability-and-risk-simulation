Pandemic Healthcare Stability Lab
=================================

Two related packages:

  pandemic_bankers/     Core algorithms, Monte Carlo, CLI (python main.py)
  pandemic_dashboard/   Flask web UI (python app.py)

Install: pip install -r requirements.txt

Quick start (web UI):
  cd pandemic_dashboard
  python app.py
  -> http://127.0.0.1:5000

Quick start (CLI analysis):
  cd pandemic_bankers
  python main.py
