Hospital Resource Stability Lab

Brief Project Report — Pandemic Healthcare Stability Analysis
September 2026 · Phases 1–3 complete

What this is

An academic simulation of hospital resource allocation under pandemic-like pressure. It asks:

  • Is the current allocation state SAFE? (Banker’s Algorithm)
  • As load grows, what is P(collapse)? (Monte Carlo)

Not a live hospital system or clinical tool. Results are model-based.

Core model (Phase 1)

  • Five resources: ICU beds, oxygen, ventilators, nurses, blood units
  • Need = Max − Allocation; Banker’s safety (SAFE / UNSAFE)
  • Monte Carlo with Wilson 95% CIs; collapse = admission failure or unsafe state
  • Per-resource elasticity: εk = Δn50 / Δck

Time-dependent hospital (Phase 2)

  • Discrete time (1 h): staffing C(t), LOS, fatigue, treatment bundles
  • ED_OVERFLOW when bundles fail — not automatic collapse
  • Triage by severity; Banker’s remains a separate snapshot each step

Empirical calibration (Phase 3)

  • OWID, UKHSA, Rees et al. 2020 LoS — provenance in data_sources.json
  • Poisson vs NB arrivals; Gamma / Weibull / Lognormal LOS compared
  • Model A (independent) vs B (severity-conditioned) vs C (calibrated)
  • No copula — observations vs assumptions vs derived vs simulated are labeled

How to run

  • Dashboard: cd pandemic_dashboard && python app.py → http://127.0.0.1:5000
  • Tests: python tests/run_tests.py (68 tests)

Limitations

  • Abstract five-resource model; max demand assumed known
  • National data ≠ your hospital’s census
  • Surge capacity often yields P(unsafe) ≈ 0
  • Not clinically validated
One-sentence pitch: A reproducible academic lab combining Banker’s deadlock avoidance, Monte Carlo collapse risk, discrete-time hospital dynamics, and optional public-data calibration — with clear separation between observations, assumptions, and simulation.
